BLOQUE A: LÓGICA & POO EN JAVA

  • Compilación: Cada archivo debe compilar limpiamente con el compilador estándar de Java (javac).

CRITERIO CE2 BLOQUE B: ESTRUCTURA & MAQUETACIÓN WEB
bloque_b/index.html & estilos.css

BLOQUE B: HTML5 SEMÁNTICO & CSS3

Construye la estructura de una página web profesional usando estándares semánticos modernos:

REQUERIMIENTOS DE MAQUETACIÓN:

  • B1. Estructura Semántica: Emplear etiquetas <header>, <main>, <section> (o <article>) y <footer>.
  • B2. Vinculación Externa: Conectar la hoja de estilos mediante <link rel="stylesheet" href="estilos.css"> dentro de <head>.
  • B3. Selectores de Clase e ID: Aplicar selectores de clase (.mi-clase) y de ID (#mi-id) en estilos.css.
  • B4. Propiedades CSS: Aplicar al menos 3 propiedades esenciales (color, background, padding, margin, border).
  • B5. Layout Moderno: Maquetar con display: flex o display: grid.

¿POR QUÉ ES CLAVE EN MÓVIL?

En React Native y Expo no existen los tags HTML del navegador, pero el 100% de la maquetación móvil nativa se realiza con Flexbox y modelos de cajas (Flex Direction, Justify Content, Align Items).

Flexbox en Web = Flexbox en Expo Mobile

CRITERIO CE3 BLOQUE C: INTERACTIVIDAD JAVASCRIPT & DOM
bloque_c/index.html & script.js

BLOQUE C: JAVASCRIPT & MANIPULACIÓN DEL DOM

Aplica interactividad mediante captura de eventos y actualización dinámica de elementos:

REQUERIMIENTOS DE INTERACTIVIDAD:

  • C1. Conexión de Script: Vincular el archivo externo con <script src="script.js"></script>.
  • C2. Cero 'var': Usar exclusivamente const (por defecto) y let (variables mutables). ¡Prohibido var!
  • C3. Funciones Nombradas: Definir funciones clásicas con nombre (ej. function saludar(...) { ... }).
  • C4. Selección y Modificación del DOM: Capturar con document.querySelector() y alterar contenido con .textContent o .innerHTML.
  • C5. Escucha de Eventos: Registrar escuchadores mediante .addEventListener('click', ...).

DEL DOM AL ESTADO MÓVIL:

Comprender cómo JavaScript manipula datos ante las acciones del usuario es el paso previo directo a dominar los Hooks (useState) y los manejadores onPress en aplicaciones móviles con Expo.
