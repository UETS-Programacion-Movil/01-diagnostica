09 · Bloque 1: GPIO Digital Pregunta Socrática
El Problema Físico

El temido Estado Flotante.

Si conectas un pulsador a 3.3V y al pin GPIO4... cuando NO lo presionas, el circuito está abierto.

¿Qué voltaje lee el ESP32 si el pin queda "al aire"?

Piénsalo como Físico:

Un pin al aire actúa como una antena: capta radiofrecuencias y ruido electromagnético del ambiente.

Su lectura oscilará caóticamente entre 0 y 1.

¿Cómo obligamos al pin a tener 0V (LOW) estable cuando nadie presiona el botón?

10 · Bloque 1: GPIO Digital Solución Técnica
La Solución Electrónica

Resistencia Pull-Down de 10 kΩ.

  • Conecta una resistencia de 10 kΩ desde GPIO4 hacia GND.
  • En reposo, la resistencia "jala" el pin a 0V (LOW fijo).
  • Al presionar, los 3.3V vencen a la resistencia y lee HIGH.
bloque_1.ino 
int estado = digitalRead(4);

if (estado == HIGH) {
  digitalWrite(23, HIGH); // LED Rojo ON
  digitalWrite(22, LOW);  // LED Verde OFF
} else {
  digitalWrite(23, LOW);  // LED Rojo OFF
  digitalWrite(22, HIGH); // LED Verde ON
}

12 · Bloque 2: Adquisición ADC Pregunta Socrática
El Lenguaje de los Microcontroladores

El ESP32 no mide "Voltios".

Giras el potenciómetro a la mitad (1.65V). El chip no entiende números decimales de voltios directamente: convierte el voltaje a números binarios enteros.

Matemática del ADC de 12 Bits

El ADC del ESP32 tiene una resolución de 12 bits ($2^{12} = 4096$ niveles posibles: de 0 a 4095).

Si 0V = 0 y 3.3V = 4095...
¿Qué número entero leerá analogRead(34) si estás en la mitad del potenciómetro?

13 · Bloque 2: Conversión Fórmula Matemática
Regla de Tres Directa

De Bits a Voltios Reales.

  • El valor en la mitad es aprox 2047.
  • Multiplicamos por 3.3V y dividimos para 4095.0.
  • Usa siempre 4095.0 con punto decimal para que C++ use división flotante.
bloque_2.ino 
int lecturaADC = analogRead(34);

// Conversión matemática precisa (0.00V a 3.30V)
float voltaje = lecturaADC * (3.3 / 4095.0);

Serial.print("ADC: ");
Serial.print(lecturaADC);
Serial.print(" | Voltaje: ");
Serial.print(voltaje, 2);
Serial.println(" V");

14 · Bloque 2: Criterio de Éxito Resultado Esperado
¿Cómo sé si mi Bloque 2 está perfecto?

Lo que se espera del Bloque 2.

Mínimo (0%)

Potenciómetro girado totalmente a la izquierda (GND / 0.00V).

ADC: 0 | Voltaje: 0.00 V

Mitad (50%)

Potenciómetro ubicado en el centro exacto (~1.65V).

ADC: 2047 | Voltaje: 1.65 V

Máximo (100%)

Potenciómetro girado totalmente a la derecha (3.30V).

ADC: 4095 | Voltaje: 3.30 V

Regla de Precisión

Dividir siempre para 4095.0 float para no redondear a cero.

float v = adc * (3.3 / 4095.0);

Construye la estructura de una página web profesional usando estándares semánticos modernos:

En React Native y Expo no existen los tags HTML del navegador, pero el 100% de la maquetación móvil nativa se realiza con Flexbox y modelos de cajas (Flex Direction, Justify Content, Align Items).
